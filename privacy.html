隐私政策

最后更新日期：

概述

开源替代（以下简称"本站"）高度重视您的隐私。本隐私政策说明了我们如何收集、使用和保护您的信息。

信息收集

本站为纯静态网站，本身不收集或存储任何个人信息。

我们不使用 Cookie 跟踪用户，不记录浏览历史，不要求用户注册，不收集邮箱地址（除非您主动通过邮件联系我们）。

第三方服务

1. 托管服务
本站托管于 GitHub Pages。GitHub 可能会根据其隐私政策收集服务器日志等基本信息。详情请参阅 GitHub 隐私声明。

2. 广告服务
本站可能展示第三方广告（如 Google AdSense）。这些广告服务商可能使用 Cookie 来提供个性化广告。您可以通过浏览器设置管理或禁用 Cookie。

3. 外部链接
本站链接到 GitHub 等第三方网站。点击这些链接后，您将受该第三方网站的隐私政策约束。

数据安全

由于本站不收集个人信息，因此不存在个人数据泄露的风险。本站通过 HTTPS 加密传输所有内容，确保您的浏览安全。

儿童隐私

本站内容面向所有年龄段的用户，不包含不适宜儿童的内容。我们不会有意收集 13 岁以下儿童的个人信息。

政策更新

我们可能会不时更新本隐私政策。更新后的政策将在本页面公布。
