# 🔄 OpenSourceAlternatives.com

发现优秀的开源替代方案，告别高价付费软件。

## 🚀 部署步骤

1. Fork 此仓库
2. 替换所有文件中的 `你的用户名` 为你的 GitHub 用户名
3. Settings → Pages → Source: `main` → `/ (root)` → Save
4. 访问 `https://mido6789.github.io/open-source-alternatives`

## 🔐 管理后台

`/admin/` → 输入密码 → 可视化管理项目、分类、广告

## 🤖 自动更新

每天自动：更新 Stars/版本号 + 新增 3-5 个项目 + 生成 sitemap
