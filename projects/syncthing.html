syncthing

⭐ 83,920 Stars 📜 MPL-2.0 替代: Resilio Sync / Dropbox

📖 项目简介

Syncthing 是一款开源的 P2P 连续文件同步工具，无需中心服务器即可在多台电脑之间安全地同步文件，保护用户数据安全，是 Resilio Sync 和 Dropbox 的隐私优先替代方案。

🔗 GitHub 项目地址

https://github.com/syncthing/syncthing

🔄 可替代的商用软件

Resilio Sync / Dropbox

📝 项目原文介绍（英文）

Syncthing is a continuous file synchronization program. It synchronizes files between two or more computers in real time, safely protected from prying eyes. Your data is your data alone and you deserve to choose where it is stored.
