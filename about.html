关于我们

我们的初心

优秀的开源软件值得被更多人看见。

在日常工作和生活中，我们常常被高昂的商用软件费用所困扰。但事实上，在开源社区中，有着无数同样优秀、甚至更加灵活的替代方案。它们自由、开放、安全，凝聚了全球开发者的智慧。

我们的使命

  • 发现与整理：收录高质量的 GitHub 开源项目，按类别整理，让每个人都能轻松找到适合自己的工具。
  • 每日追踪：自动更新项目的 Stars、版本号等动态数据，确保信息的时效性和准确性。
  • 尊重开源：所有项目版权归原作者所有，我们严格注明出处，绝不篡改项目信息。
  • 保持中立：客观介绍每个项目，不偏袒、不收费推广。

我们的原则

  • ✅ 所有收录项目均来自 GitHub 开源社区
  • ✅ 严格注明原作者和出处
  • ✅ 绝不篡改项目信息，保持客观中立
  • ✅ 如涉及侵权，一经核实立即删除
